# 合成大gaygay 💐

一个网页版「合成大西瓜」风格的下落合成小游戏，婚礼主题。
纯 HTML + CSS + JavaScript，不需要安装任何东西，双击就能玩。

---

## 一、怎么打开它

### ⚠️ 先注意：现在需要联网
从第 2 阶段开始，游戏用了 **Matter.js**（一个物理引擎）。
它通过网址加载，所以：
- **第一次打开需要联网**
- 如果断网了，页面会正常显示，但球不会动，Console 里会有红色的
  `Matter is not defined`

想彻底摆脱网络依赖？看第十节「把 Matter.js 存到本地」。

### 方法 1：最简单（不推荐，但能看）
直接双击 `index.html`，浏览器会打开它。

> ⚠️ 注意：用这种方法打开时，网址是 `file:///...`，
> 有些浏览器会拦截读取本地图片，**球的图片可能不显示**。
> 如果遇到「球是空白的」，请用下面的方法 2。

### 方法 2：Live Server（推荐，也是以后写代码的用法）
1. 用 VS Code 打开这个文件夹（`文件 → 打开文件夹`）
2. 在左边的文件列表里点一下 `index.html`
3. 右下角会弹出一个 `Go Live` 按钮，点它
   （如果没有，就装一个叫 **Live Server** 的扩展，作者是 Ritwick Dey）
4. 浏览器自动打开 `http://127.0.0.1:5500/index.html`

**改完代码保存（Ctrl + S），网页会自动刷新** —— 这就是为什么推荐用它。

## 二、怎么看有没有报错（非常重要）

写代码一定会出错，学会看报错能省掉 90% 的时间。

1. 在浏览器里按 **F12**（或者右键 → 检查）
2. 点上方的 **Console（控制台）** 标签
3. 正常情况下你应该看到：

```
游戏初始化成功
游戏区尺寸：480 × 660 像素
一共 16 个等级：
  1 级：直径 56px，图片 assets/level1.jpg
  2 级：直径 63.28px，图片 assets/level2.jpg
  ...
  16 级：直径 350.24px，图片 assets/level16.jpg
抽球概率： {1: 30, 2: 25, 3: 20, 4: 15, 5: 7, 6: 3}
Matter.js 版本：0.19.0
👉 把鼠标移进游戏区，出球口会跟着走
👉 【点一下鼠标】就能放球，位置由出球口决定
👉 两个【同级】的球碰在一起就会合体升级，还会加分！
👉 球堆到危险线以上、停住 2 秒，这局就结束了
```

每成功放一颗球，Console 里还会多一行：
```
放了一颗 3 级球（x=240），目前场上 1 颗，下一个是 5 级
```

每次合成成功，还会多一行：
```
合成成功！+3 分，总分 7
```

结束的时候，Console 还会多一行：
```
💔 婚礼举办失败！ 本局得分 7
```

4. 如果看到 **红色的字**，那就是报错。报错里会写：
   - **文件名 + 行号**（比如 `game.js:120`）→ 去那一行看
   - **错误类型**，常见的有：
     - `Cannot read properties of null` → 你写的 id 在 HTML 里不存在，打错字了
     - `xxx is not defined` → 变量名拼错了
     - `404 (Not Found)` → 图片或文件路径不对

**把红色报错整段复制给我，我就能帮你改。**

## 三、怎么玩（现在能做什么）

| 你想做的事 | 怎么做 |
|---|---|
| 瞄准 | 把鼠标（或手指）在游戏区里**左右移动**，出球口跟着走 |
| 放球 | **点一下游戏区**，球就从出球口掉下来 |
| 合成 | 让**两个相同的球**碰在一起，自动合体升级 + 加分 |
| 重开 | 点「重 新 开 始」按钮 |

**现在能玩的：** 球会掉下来、会互相弹开、会堆叠，**两个相同的球撞在一起会合成升级并加分**；
记分板上的「下一个」会**提前告诉你下一颗是什么球**，方便你规划落点；
球堆到危险线以上、停住 2 秒，这局就**结束**了；
**最高分会自动记住**，关掉浏览器再打开还在。

**全部 8 个阶段都做完了 🎉** —— 现在就差把它放到网上（见第十一章）。

**目标：** 一路合成到 **16 级球**（最大那颗）。

## 四、文件都是干什么的

```
合成大gaygay/
├── index.html      ← 页面结构（有哪些东西）
├── style.css       ← 样式（长什么样）
├── game.js         ← 逻辑（怎么玩）
├── README.md       ← 就是这个文件
└── assets/
    ├── level1.jpg  ← 1 级球
    ├── level2.jpg
    ├── ...
    └── level16.jpg ← 16 级球（最大）
```

**为什么图片要放在 `assets` 文件夹里？**
因为根目录只有 4 个文件，一眼就能看清项目结构；
图片归图片，代码归代码，以后加音效、字体也照这个分法。

**关于 Matter.js**
游戏用 CDN 网址加载它（写在 `index.html` 里）：

```html
<script src="https://cdn.jsdelivr.net/npm/matter-js@0.19.0/build/matter.min.js"></script>
```

它负责算「球怎么滚、怎么撞」，我们只管把结果显示出来。

## 五、游戏的 16 个等级

每一级的图片都显示成一个**圆**（不是方块）。
代码用 `border-radius: 50%` 把方图裁成圆，用 `object-fit: cover` 保证**不变形**
（会把超出的部分裁掉，绝不拉伸）。

| 等级 | 直径 | 等级 | 直径 |
|---|---|---|---|
| 1 | 56 px | 9 | 148.87 px |
| 2 | 63.28 px | 10 | 168.23 px |
| 3 | 71.51 px | 11 | 190.1 px |
| 4 | 80.8 px | 12 | 214.81 px |
| 5 | 91.31 px | 13 | 242.73 px |
| 6 | 103.18 px | 14 | 274.29 px |
| 7 | 116.59 px | 15 | 309.95 px |
| 8 | 131.75 px | 16 | 350.24 px |

> 尺寸是 `56 × 1.13 的 (等级-1) 次方` 算出来的。
> 16 级球宽 350px，游戏区宽 480px —— 也就是说最大的球占了大半个通道。

**觉得某张图裁出来不好看？**
（比如人物的脸被切掉了）打开 `game.js`，找到 `IMAGE_FOCUS`，加一行：

```js
const IMAGE_FOCUS = {
  3:  { x: 50, y: 30 },   // 3 级球：只看上半部分
  8:  { x: 50, y: 70 },   // 8 级球：只看下半部分
};
```

- `x`: `0%` = 左边，`50%` = 中间，`100%` = 右边
- `y`: `0%` = 上边，`50%` = 中间，`100%` = 下边

**想改抽球概率？** 打开 `game.js` 的 `getSpawnWeights()`。
那 6 个数字加起来是 100，可以直接当百分比读。

## 六、配色怎么改

所有颜色都写在 `style.css` 最上面的 `:root { }` 里。
想换风格，只改那一段就行，不用翻整个文件：

```css
:root {
  --ivory:      #FBFCFE;  /* 页面底色：象牙白 */
  --sky-strong: #8EC6E8;  /* 主色：淡天蓝 */
  --hydrangea:  #C5D8EA;  /* 花艺雾蓝 */
  --sage:       #8FA98C;  /* 绿叶绿 */
  --gold:       #D9C9A8;  /* 极细描边金 */
  --ink:        #4C5766;  /* 主文字 */
  --danger:     #E5707A;  /* 危险线红 */
}
```

### ✅ 第 5 阶段：合成！（已完成）
**这一步新加了什么：**
- **两个同级的球碰在一起 → 合成一个高一级的球！**（这是整个游戏的核心）
- 合成会**加分**，分数显示在左上角（越高级的球分越多）
- 合成时有**三种动画**：旧球「噗」地消失、一圈光晕炸开、新球弹出来
- 新球会**继承两个旧球的速度**，快速下落的球合成后不会僵在半空

**你要做的测试：**
- [ ] 放两颗 **1 级球**，让它们撞在一起 → 变成一个 **2 级球**，左上角分数 +1
- [ ] 再放两个 2 级球 → 合成 3 级球，分数 +3
- [ ] 合成瞬间能看到**光晕炸开**和**新球弹出**的动画
- [ ] **一个大球撞一个小球**（不同级）→ 只会互相弹开，**不会合成** ✅ 正确
- [ ] 三个同级球挤在一起 → **只合成一对**，不会三个一起消失
- [ ] 一路合到 **16 级球** → 两个 16 级球碰在一起**不会再合成**（到顶了）
- [ ] 点「重 新 开 始」→ 球和**分数都归零**

> 💡 分数规律：合成 2 级 +1 分、3 级 +3 分、4 级 +6 分……每级递增。
> 合成一颗 16 级球理论上需要 16384 颗 1 级球，所以能合出 16 级非常不容易。

### ✅ 第 6 阶段：「下一个」预览（已完成）
**这一步新加了什么：**
- 记分板中间的「下一个」卡片，以前是个**灰灰的空圆**，现在会显示**真的球图**
- 每次换球它都会**闪一下**，提醒你「换球了，快看一眼」
- 如果下一个是 **5 级或 6 级大球**，会额外描一圈**金边**，一眼就知道好运来了
- 鼠标悬停在上面能看到「下一个：3 级球」的提示

**你要做的测试：**
- [ ] 打开页面 → 「下一个」卡片里是个**真的球图**（不是灰圆）
- [ ] 放一颗球 → 「下一个」**换成新球并闪一下**
- [ ] 对照一下：**HUD 显示的球**、**出球口里那颗球**、**实际掉下来的球**，三者永远一样
- [ ] 一直放球，直到抽到 **5 级或 6 级** → 卡片上有**金边**
- [ ] 点「重 新 开 始」→ 预览换新球并闪一下
- [ ] Console 无红色报错

> 💡 为什么这个很重要？因为没有预览，玩家就只能「球掉了才知道是什么」，
> 没法提前规划落点。有了预览，游戏才真正有了**策略**。

### ✅ 第 7 阶段：结束判定（已完成）
**这一步新加了什么：**
- 有球**停住**并且顶部**超过危险线**，持续 2 秒，这局就**结束**
- 危险线上有球压着时，线会**变红、闪得更急**，提醒你赶紧想办法
- 结束时会弹出**结算面板**，显示本局得分
- 面板按分数显示两种结局：**> 1200 分**显示「您已成功守卫他们的爱情，恭喜」，否则显示「婚礼举办失败 / 是否需要再次举办」
- 结束之后画面**冻结**，不能再放球；点「重 新 开 始」才恢复

**你要做的测试：**
- [ ] 把球堆高，让某颗球**停住**且顶部**过危险线** → 2 秒后弹出「婚礼举办失败」面板
- [ ] 危险线在球压上来时会**变红、闪得更快**
- [ ] 结算面板上显示的**分数**和左上角一致
- [ ] 结束之后**点不动**（不能再放球了）
- [ ] 点「重 新 开 始」→ 面板消失，能重新玩
- [ ] Console 无红色报错

> 💡 为什么要有 2 秒缓冲？因为球刚扔下来时会从危险线上方「路过」，
> 那不算输。只有**停住**还压在线上，才说明真的堆太高了。

### ✅ 第 8 阶段：最高分（已完成）
**这一步新加了什么：**
- 分数一旦**超过历史最高分**，就立刻刷新最高分，并存进 `localStorage`
- **关掉浏览器再打开**，最高分还在
- 打破纪录时 Console 会打印「🎉 新纪录！」

**你要做的测试：**
- [ ] 玩一局，合成几个球让分数上去 → 右上角「最高分」跟着涨
- [ ] **刷新页面（F5）** → 分数归零了，但最高分还在
- [ ] 关掉浏览器整个重开 → 最高分依然在
- [ ] 再玩一局但分数**没超过**上次 → 最高分不变
- [ ] Console 无红色报错

> 💡 为什么分数归零但最高分还在？因为「当前分数」存在内存里（刷新就没），
> 「最高分」存在 `localStorage`（关掉浏览器也在）。这是两种不同的存储。

## 八、把 Matter.js 存到本地（可选，但推荐）

如果你不想每次玩都联网（或者想部署到没网的地方），
可以把 Matter.js 下载下来，改成本地引用：

**第 1 步：下载**
在浏览器里打开这个网址，然后按 `Ctrl + S` 保存：
```
https://cdn.jsdelivr.net/npm/matter-js@0.19.0/build/matter.min.js
```

**第 2 步：放到项目里**
保存到 `assets` 旁边的 `lib` 文件夹（没有就新建一个），
文件名保持 `matter.min.js`：
```
合成大gaygay/
├── index.html
├── style.css
├── game.js
├── lib/
│   └── matter.min.js
└── assets/
```

**第 3 步：改一行 HTML**
打开 `index.html`，找到最下面那行 `<script src="https://cdn...">`，
把网址换成 `lib/matter.min.js`：

```html
<!-- 改之前 -->
<script src="https://cdn.jsdelivr.net/npm/matter-js@0.19.0/build/matter.min.js"></script>

<!-- 改之后 -->
<script src="lib/matter.min.js"></script>
```

保存，刷新页面。Console 里还是会出现 `Matter.js 版本：0.19.0`，说明成功了。
这时候**断网也能玩**。

## 九、这一阶段的 JavaScript 小知识

第 2 阶段用到的东西，都在这几个概念里：

| 概念 | 用在哪 | 一句话解释 |
|---|---|---|
| `let` vs `const` | 文件开头 | `let` 能改，`const` 不能改。`STAGE_WIDTH` 要改所以用 `let` |
| `Engine.create()` | `engine` | 造一台物理世界的发动机 |
| `engine.gravity.y` | `engine` | 重力，越大掉得越快 |
| `Bodies.circle(x,y,r)` | `createBall` | 造一个圆形的物理物体 |

**为什么用 Pointer Events 而不是 mouse + touch 两套？**
`pointermove` 是新一代写法，**鼠标、手指、触控笔一套代码全搞定**，
不用再写 `mousemove` 和 `touchmove` 两份逻辑。

**为什么球用 `<img>` 而不是画在 canvas 上？**
因为 `<img>` 图片最清晰、不用自己处理圆角和阴影、
出错时还能右键「检查」看到它在哪 —— 对新手友好很多。

遇到问题时，告诉我这三样，我基本一下就能定位：

1. **你在做什么** —— 比如「我点了重新开始按钮」

## 十一、以后怎么放到网上

这个项目是纯静态的，可以直接传 GitHub Pages 免费托管：

1. 新建一个 GitHub 仓库（公开）
2. 把这些文件传上去（`index.html` / `style.css` / `game.js` / `assets/` 整个文件夹）
3. 仓库 → `Settings` → `Pages` → `Source` 选 `Deploy from a branch`
4. Branch 选 `main`，文件夹选 `/ (root)`，点 Save
5. 等 1~2 分钟，网址就是 `https://你的用户名.github.io/仓库名/`

发给朋友，手机也能玩。
